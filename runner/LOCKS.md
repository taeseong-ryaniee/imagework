## SAM3 requirements lock

The lock was generated with `uv 0.11.19`, targeting CPython 3.12 and
`x86_64-manylinux_2_17`, from the direct image-inference closure of SAM3
commit `5dd401d1c5c1d5c3eedff06d41b77af824517619`. It uses exact versions and
PyPI SHA-256 hashes. It deliberately does not install `torch`, `torchvision`,
`numpy`, or `Pillow`: the Colab base runtime supplies those GPU-coupled
packages, and the remote worker must preflight their supported versions before
installing this lock with `--no-deps --require-hashes`.

`einops` is included because the pinned SAM3 source imports it from
`sam3/sam/rope.py`, although that import is absent from the upstream project
metadata. `iopath 0.1.10` publishes only a source distribution; its exact
source-distribution hash is present in the lock. Do not add `--only-binary` to
the install command, because that would make the pinned source-only dependency
uninstallable. First install the separately pinned build tools, then disable
build isolation so pip cannot fetch an unpinned build backend:

```sh
python -m pip install --no-deps --require-hashes -r sam3-build-requirements.lock
python -m pip install --no-build-isolation --no-deps --require-hashes -r sam3-requirements.lock
```

Regenerate only after a reviewed dependency update:

```sh
uv pip compile --no-deps --generate-hashes --no-annotate --no-header \
  --python-version 3.12 --python-platform x86_64-manylinux_2_17 \
  sam3-runtime-closure.in -o sam3-requirements.lock
```

The reviewed input pins the 21 packages present in the resulting lock. Verify
the resulting SHA-256 and a fresh Python 3.12 install before changing the
worker's matching expected hash.

## VTracer lock

VTracer tag `0.6.0` resolves to commit
`1080c562cefcc345b668f5e8d5eadb73797383ea` and does not publish a lock file.
This lock was generated from that checked-out source using the official Rust
1.80.0 distribution, then verified with:

```sh
cargo build --release --locked --manifest-path cmdapp/Cargo.toml
```

The remote worker verifies the official Linux Rust archive hash before use,
copies this file to the cloned VTracer repository root, and must build with
`--locked`. Never run an unlocked Cargo resolution in the remote job.
